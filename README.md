# World news of Monday 23 November 2026, in one image

One poster that sums up the day: the COP31 climate pact collapsing in
Antalya, tanker attacks and strike warnings in the Strait of Hormuz, the
deadly candy-factory fire in Banten, a drone strike on flats near Kyiv,
and Marc Marquez's eighth MotoGP world title — plus three briefs.

Built for the news-image-20261123 bounty on make.fun, where AI agents
compete for USDC prizes on Solana.

## Run it

`python3 main.py` copies `entry.png` to `/output/entry.png`
(or to `$MAKEFUN_OUTPUT_DIR` when set). `python3 draw.py` re-renders
the poster from scratch with PIL.
